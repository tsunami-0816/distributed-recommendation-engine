# 分布式智能推荐引擎 - 傻瓜式操作指南

> 本指南写给完全不懂技术的用户。跟着一步一步做，就能把项目跑起来并体验完整功能。
>
> **关于脚本语言**：启动脚本里的文字是英文的，这是为了避免 Windows 中文编码导致窗口闪退。不用担心，本指南末尾有【脚本提示中英文对照表】，照着看就行。

---

## 一、这是个什么项目？

简单说，这是一个**"猜你喜欢"推荐系统**。就像淘宝首页给你推商品、抖音给你推视频一样，这个系统会根据用户的行为（点击、收藏等），给用户推荐可能感兴趣的商品。

项目包含两部分：
- **后端**：藏在背后算推荐结果的程序（运行在 8084 端口）
- **前端**：你在浏览器里看到的页面（运行在 5174 端口）

**好消息**：这个项目不需要安装数据库、不需要装 Redis、不需要装 Kafka，所有数据都存在内存里，开箱即用。

## 二、你电脑上需要先装好的东西

只需要 3 个软件，如果已经装过可以跳过：

| 软件 | 版本要求 | 下载地址 | 怎么装 |
|------|---------|---------|--------|
| JDK（Java开发包） | 17 或更高 | https://adoptium.net/ | 选 Temurin 17 LTS，下载 `.msi` 安装包，双击下一步到底 |
| Maven（Java构建工具） | 3.6 或更高 | https://maven.apache.org/download.cgi | 下载 zip 解压，把 `bin` 目录加到环境变量 Path |
| Node.js | 16 或更高 | https://nodejs.org/ | 选 LTS 长期支持版，下载 `.msi` 双击下一步到底 |

> 不确定装没装？没关系，继续往下看，有脚本自动帮你检查。

## 三、第一步：检查环境（只需做一次）

1. 打开项目文件夹，进入 `scripts` 文件夹
2. 找到 **`01-check-env.bat`**，双击运行
3. 会弹出一个黑色窗口，自动检查你电脑上的软件
4. 看到下面这样就说明全部通过了（英文提示，对照后面的表格看）：

```
========================================
   Distributed Recommendation Engine
   Environment Check
========================================

[1/3] Checking Java (need 17 or higher)...
  [OK] Java version: "17.0.19"

[2/3] Checking Maven (need 3.6 or higher)...
  [OK] Maven version: 3.9.16

[3/3] Checking Node.js (need 16 or higher)...
  [OK] Node.js version: v20.20.2
  [OK] npm version: 10.8.2

========================================
  All checks passed! You can start the project now.
  Please double-click: 04-start-all.bat
========================================
```

如果有 `[FAIL]` 字样，按照窗口里提示的下载地址装好，再运行一次这个脚本。

## 四、第二步：一键启动项目

1. 在 `scripts` 文件夹里，找到 **`04-start-all.bat`**，双击运行
2. 窗口会提示你按任意键继续，按一下回车
3. 然后会发生这些事（不用管，等着就行）：
   - 弹出第一个黑色窗口，标题是 **"Backend-8084"**，开始编译启动后端
   - 等 5 秒后，弹出第二个黑色窗口，标题是 **"Frontend-5174"**，开始启动前端
   - 前端启动后，浏览器会自动打开页面

4. **关键判断**：看第一个后端窗口，等它出现下面这行字，说明后端启动成功了：
   ```
   Started RecommendationEngineApplication in X.XXX seconds
   ```
   一般需要 10~30 秒（第一次更久，因为要下载依赖）。

5. 这时候浏览器如果已经打开了页面但显示空白或报错，按 **F5 刷新一下**就好了。

> 两个黑色窗口就是服务在运行，**不要关闭它们**！关了服务就停了。最小化就行。

## 五、第三步：走一遍核心主流程

启动成功后，浏览器会打开 `http://localhost:5174`，你会看到一个商品推荐页面。

> 注意：这个系统**没有注册登录功能**。用户身份就是顶部的"用户ID"，随便填一个名字就行，默认是 `u_10001`。

### 5.1 看首页推荐（你现在就在这）

- 页面顶部有导航栏：首页推荐、猜你喜欢、相关推荐、搜索推荐、热门榜单、用户画像
- 页面中间会显示一排推荐商品卡片，每个卡片有：
  - 商品名称、价格、标签
  - 推荐排名、打分（score）
  - 召回来源（这个商品是通过什么方式推荐给你的）
- 页面上方有"返回数量"可以调，点"刷新推荐"可以重新获取

**你现在看到的，就是系统给用户 `u_10001` 推荐的商品列表。**

### 5.2 切换用户（体验不同用户的推荐）

1. 看页面右上角，有个输入框，前面写着"用户ID:"
2. 把里面的 `u_10001` 改成别的，比如 `u_20002`
3. 点旁边的 **"切换"** 按钮
4. 页面会刷新，这就是给新用户推荐的商品了

> 不同用户看到的推荐可能不一样，因为系统会根据用户ID做 A/B 分组和个性化计算。

### 5.3 点击商品（模拟用户行为，影响推荐）

1. 切回用户 `u_10001`（在右上角输入框改回去，点切换）
2. 在推荐商品列表里，随便点一个商品卡片上的 **"点击"** 或 **"收藏"** 按钮
3. 点完后，系统会记录这个行为
4. 点页面上的 **"刷新推荐"** 按钮
5. 你会发现推荐结果可能变化了——因为你刚才的行为影响了推荐

> 这就是推荐系统的核心：**用户行为 → 更新画像 → 影响推荐结果**。

### 5.4 看用户画像（行为是怎么影响推荐的）

1. 点顶部导航栏的 **"用户画像"**
2. 你会看到当前用户的详细画像，包括：
   - **长期画像**：喜欢的品类、标签偏好、活跃度、活跃时段、价格偏好
   - **短期画像**：最近点击的商品、最近收藏的商品、最近浏览的品类
   - **融合标签**：综合长短期后得出的兴趣标签
3. 如果你刚才点了某个商品，这里的"最近点击商品"会出现它

### 5.5 看热门榜单

1. 点顶部导航栏的 **"热门榜单"**
2. 这里展示全站最热门的商品排行，按热度分数排序
3. 能看到每个商品的点击数、收藏数

### 5.6 体验其他推荐场景

顶部导航栏还有几个场景，可以都点一遍看看：

| 场景 | 说明 | 怎么操作 |
|------|------|---------|
| **猜你喜欢** | 根据用户画像个性化推荐 | 直接看，或点刷新 |
| **相关推荐** | 给一个商品，推荐相似的 | 输入一个商品ID（比如 `i_16094`），点获取 |
| **搜索推荐** | 输入关键词，推荐相关商品 | 输入关键词（比如 `耳机`），点搜索 |

### 5.7 进入管理后台（看系统运行数据）

1. 在任意演示页面，点右上角的 **"管理后台"** 按钮（齿轮图标）
2. 或者直接在浏览器地址栏输入 `http://localhost:5174/admin/dashboard`
3. 你会进入管理后台，左侧有菜单：
   - **系统概览**：请求量、延迟、缓存命中率、QPS、健康状态等实时指标
   - **A/B 实验管理**：查看和管理 A/B 分流实验
   - **模型管理**：查看推荐模型（DeepFM/XGBoost）的状态和指标
   - **系统配置**：修改推荐参数（每页数量、缓存时间、模型超时等）
   - **缓存管理**：查看缓存状态、手动清理缓存
   - **特征一致性**：检查训练和推理时的特征是否一致

> 管理后台不需要登录，系统自动带上了开发用的 API Key（`admin-dev-key`）。

## 六、怎么停止服务？

用完了想关掉：

1. 进入 `scripts` 文件夹
2. 双击 **`05-stop-all.bat`**
3. 它会自动找到并关闭后端和前端进程
4. 如果还有黑色窗口没关，手动点右上角 × 关掉就行

## 七、脚本文件说明（都在 scripts 文件夹里）

| 文件名 | 作用 | 什么时候用 |
|--------|------|-----------|
| `01-check-env.bat` | 检查 Java/Maven/Node 是否装好 | 第一次使用前，或不确定环境时 |
| `02-start-backend.bat` | 只启动后端服务 | 前端已经在跑，只想单独重启后端时 |
| `03-start-frontend.bat` | 只启动前端服务 | 后端已经在跑，只想单独重启前端时 |
| `04-start-all.bat` | 同时启动后端+前端 | **日常使用就点这个** |
| `05-stop-all.bat` | 停止后端和前端 | 用完了关闭服务时 |

## 九、常见问题（FAQ）

### Q1：双击脚本后窗口一闪就没了？
A：这通常是编码问题。本项目的脚本已经全部改成英文，避免了中文编码闪退。如果还是闪退，可能是：
- 系统 PATH 里没有 Java/Maven/Node，脚本检测到后报错退出。可以先运行 `01-check-env.bat` 确认。
- 脚本所在路径包含特殊字符（如中文、空格、特殊符号）。建议把项目放在纯英文路径下，比如 `D:\project\recommendation-engine\`。

### Q2：后端窗口一直卡在下载依赖？
A：第一次启动 Maven 要下载很多依赖包，国内网络可能慢。如果卡住不动，可以按 Ctrl+C 停止，再重新运行。也可以配置 Maven 阿里云镜像加速。

### Q3：浏览器打开页面是空白的？
A：大概率是后端还没启动完。看后端窗口有没有出现 `Started RecommendationEngineApplication`，出现后按 F5 刷新页面。

### Q4：页面提示"网络异常"或"请求失败"？
A：后端没启动或者崩了。看后端窗口有没有报错，把错误信息截图发给技术人员。

### Q5：端口被占用了怎么办？
A：如果 8084 或 5174 端口被别的程序占用：
- 运行 `05-stop-all.bat` 先停掉可能残留的进程
- 或者修改配置：后端端口在 `recommendation-engine/src/main/resources/application.yml` 的 `server.port`，前端端口在 `recommend-admin/vite.config.js` 的 `server.port`

### Q6：改了代码怎么生效？
A：后端改了 Java 代码需要重启后端（关掉后端窗口，重新运行 `02-start-backend.bat`）；前端改了 Vue 代码会自动热更新，保存就生效。

### Q7：数据会保存吗？
A：不会。这个项目所有数据都在内存里，服务一停就全没了。重启后是全新的初始状态。这是演示项目的正常设计。

### Q8：怎么看接口文档？
A：后端启动后，浏览器访问 `http://localhost:8084/swagger-ui.html`，可以看到所有 API 接口的在线文档，还能直接在页面上测试接口。
